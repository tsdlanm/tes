# TaskFlow

Aplikasi manajemen tugas dibuat dengan React Native (Expo).

## Menjalankan

```bash
npm install
npx expo start        # scan QR dengan Expo Go (Android/iOS)
npx expo start --web  # pratinjau di browser
```

Fitur: progres harian, filter Semua/Aktif/Selesai, kategori & prioritas, tambah/hapus/selesaikan tugas.
