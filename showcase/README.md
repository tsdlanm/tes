# RN UI Showcase

Aplikasi demo (Expo / React Native) yang memamerkan banyak kemampuan UI dan animasi.

```bash
npm install
npx expo start        # scan QR dengan Expo Go
npx expo start --web  # pratinjau di browser
```

Tab: Animasi · Gestur · Komponen · Layout · Grafik. Tema gelap/terang lewat Switch di header.
Hanya memakai API inti React Native + `expo-linear-gradient`.
